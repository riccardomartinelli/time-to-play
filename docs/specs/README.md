# Specifiche di feature

Un file per feature: `NNN-nome-feature.md` (es. `001-movimento-giocatore.md`).

Struttura consigliata:
- **Obiettivo**: cosa deve ottenere il giocatore / il sistema
- **Comportamento**: descrizione dettagliata
- **Criteri di accettazione**: elenco verificabile
- **Fuori scope**
- **Dipendenze**

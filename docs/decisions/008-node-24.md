# 008 Node.js 24 LTS

- **Data**: 2026-10-10
- **Contesto**: il progetto usava Node.js 20, fuori supporto da aprile 2026 (niente più aggiornamenti di sicurezza). Inoltre Vitest 5 richiede almeno Node.js 22.12.
- **Decisione**: Node.js **24**, la versione LTS attiva, in tutti i punti:
  - sviluppo: `.nvmrc` (`nvm use`) e `engines.node >= 24` in `package.json`;
  - CI: `actions/setup-node` legge la versione da `.nvmrc`;
  - immagini Docker: `node:24.21-alpine` per build e server;
  - build del server: `tsup --target node24`, tipi `@types/node` 24.
- **Alternative considerate**:
  - Node.js 22: ancora supportato ma già in sola manutenzione, con fine supporto più vicina;
  - Node.js 26: non ancora LTS alla data della decisione (lo diventa a fine ottobre 2026).
- **Conseguenze**:
  - Vitest aggiornato alla 5; i test esistenti passano senza modifiche;
  - npm 11 (incluso in Node.js 24) blocca gli script di installazione non approvati: oggi riguarda solo esbuild e fsevents, non necessari al funzionamento;
  - il prossimo passaggio sarà a Node.js 26 quando diventerà LTS, cambiando insieme `.nvmrc`, `engines`, Dockerfile, target di tsup e `@types/node`.
